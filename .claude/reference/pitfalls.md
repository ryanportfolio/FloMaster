# Pitfalls

> Accumulated project-specific gotchas. Dated entries, newest at the bottom. If this file exceeds ~200 lines, split by area (`pitfalls-<area>.md`) and update the CLAUDE.md index.

- **2026-10-05 · Git Bash turns a `/` page argument into a Windows path.** `node scripts/shoot.mjs /` navigated to `http://localhost:4321C:/Program Files/Git/`. Prefix page-path commands with `MSYS_NO_PATHCONV=1`.
- **2026-10-05 · Astro 7 runs one preview server at a time.** A second `astro preview` exits with "Another astro preview server is already running", and a kill queued in a Node `exit` handler never runs, so the first server lingered. Use `scripts/lib/preview.mjs` (reuses a running server, stops its own with a synchronous `taskkill`), or `npx astro preview stop`.
- **2026-10-05 · opentype.js 2.0 writes NaN into Cinzel's "M".** One horizontal segment has an undefined x, so `getPath().toPathData()` emits `LNaN`, and whole-string layout adds a ligature bug on top. `scripts/build-logo.mjs` lays out letter by letter and serializes path commands itself, carrying the previous point forward.
- **2026-10-05 · The check scripts only test the build on port 4321.** Every `scripts/check-*.mjs` calls `startPreview(4321)`, which reuses whatever preview answers there, so in a second worktree they silently test the main workspace's build. To check another build, serve its `dist/` on its own port with a plain static server (one existed for the repair-story bakeoff at `.tmp/arena/repair-story/serve.mjs`) and point a copy of the script at it. That server does not compress, so its page weights read about 100 KB higher than `astro preview`; compare raw HTML sizes instead.
- **2026-10-05 · `cmd //c mklink /J` fails from Git Bash.** MSYS rewrites `/J`, and mklink answers `Invalid switch`. Create a `node_modules` junction with Node instead: `fs.symlinkSync(target, path, "junction")`.
- **2026-10-05 · 2x full-page phone screenshots of long pages come back scrambled.** The home page at 375 px is about 14,000 CSS px tall, so a `deviceScaleFactor: 2` full-page capture is about 28,000 device px, past Chrome's 16,384 px capture limit; the image repeats the top of the page partway down. The page itself is fine. For review, capture long pages at device scale 1, or capture viewport-sized pieces.
- **2026-10-05 · Clicking a `tel:` link in automated Chrome blocks every later navigation in that page.** Chrome holds an "open this app?" prompt, so a following click or `goto` never commits (`waitForURL` timed out). Click `tel:` links last, or in their own page.
- **2026-10-05 · Speculation-rules prerenders never activate while Playwright is attached.** Chrome reports `PrerenderingDisabledByDevTools` for every attempt, with any context options. Scripts can only confirm an attempt starts (CDP `Preload` events); check activation by hand in plain Chrome (DevTools, Application, Speculative loads).
- **2026-10-05 · `getComputedStyle(document.documentElement, "::view-transition-…(name)")` for a group that does not exist crashes the Chrome tab** ("Target crashed"). Only read view-transition pseudo-elements that the current pass creates (for example `fm-tide` only in the full pass).
- **2026-10-05 · A view-transition root picture keeps the page background behind named elements.** Giving the header its own group does not leave a see-through hole in the root picture: its slot shows the body background (paper white), so a header that moves during the transition uncovers a white strip. The site avoids it by keeping the header at the same place on every page: the prototype review bar rides inside the sticky header instead of scrolling away above it.
- **2026-10-05 · Never move a view transition's animation start times after it starts.** The band and the reveal run on the compositor, which keeps drawing frames while the main thread is stuck on a slow first frame; moving `startTime` forward afterwards drew the band backwards (gone for a frame, then back higher up). Presented frames only show this in a trace filmstrip, not in `requestAnimationFrame` timings. The retired `check-transition.mjs` (backup in `D:\CoreWise\_artifacts\FloMaster\page-transition-backup\`) forced an 80 ms stall and checked the filmstrip.
- **2026-10-05 · Chrome does not scroll a focused element that is already partly in view**, even when its lower part sits under the phone bottom bar or its upper part under the sticky top area. With the taller prototype top area this made `check-keyboard` fail on the callback textareas and the home service cards; `TagSwitch.astro` scrolls such an element clear on `focusin`, only when the last input was a key press: scrolling on mouse focus made a click inside a focusable panel, a text field or the repair slider jump the page. `:focus-visible` cannot make that call, because Chrome sets it for clicked text fields, a mouse-focused range input and focus moved by script.
- **2026-10-05 · Subagents share one `mcp__playwright-iso__*` browser.** The MCP server belongs to the session, so parallel subagents from one session drive the same tab: one reviewer's navigation moved another reviewer's page mid-check. `--isolated` keeps the profile throwaway; it does not give each agent its own browser. Parallel browser work in subagents goes through `launchPlacedChrome()`, one Chrome per agent.
- **2026-10-06 · The `disabled-by-default-cc.debug` trace category repaints the whole page at the next input.** With it on, the first touch after tracing starts shows a full `#document` paint and a re-raster of every layer that the page never does by itself; an earlier diagnosis of a drag-start stall rested on that repaint. Trace frame stalls with `devtools.timeline`, `gpu`, `skia` and `disabled-by-default-skia.shaders` (shows `shader_compile` events), and start tracing at page load if `cc.debug` is needed.
- **2026-10-06 · A tilted element that leaves its compositor layer costs a one-time GPU stall.** The rotated home business card (`.hero-card`, `rotate(-2deg)`) got its own layer whenever the moving X-ray lens's layer box overlapped it, and dropped back into the page layer when the lens left. The first drop in a fresh Chrome compiled about six new GPU shaders (55 to 65 ms) and held the next frame. Check `LayerTree.compositingReasons` for `Overlap` layers that come and go as something moves; paint the moving part above them, or keep them on a layer for good.
- **2026-10-06 · sharp's `erode()` grows white areas and `dilate()` shrinks them** (the reverse of the usual morphology naming on a white-on-black mask). Building feathered masks for the scroll-zoom layers took two failed composites before this showed. Check a mask's white area after each step.
- **2026-10-06 · sharp turns raw single-channel input into 3 channels.** A raw 1-channel buffer passed to `sharp(buf, { raw: { channels: 1 } })` comes out with 3 channels unless the pipeline adds `.extractChannel(0)`, which breaks `joinChannel` alpha composites.
- **2026-10-06 · Windows treats `BRIEF.md` and `brief.md` as one file.** NTFS is case-insensitive, so the wow-animation skill's `BRIEF.md` written into a run folder that already held the orchestrator's `brief.md` overwrote it (restored from a copy). Give run files distinct names, not names that differ only in case.
- **2026-10-06 · A `.visually-hidden` span mid-word splits what Chrome reads.** The class is `position: absolute`, so Chrome treats the span as its own block: `After-hours<span class="visually-hidden">: $0 on this quote</span>` came out as "After-hours : $0 on this quote", and `Term <span>`-style pieces around a number as "Term 1 : Call-out fee", read by a screen reader as separate lines. Hide the visible words with `aria-hidden="true"` and put the whole spoken phrase in one hidden span (`<span aria-hidden="true">After-hours</span><span class="visually-hidden">After-hours: $0 on this quote</span>`).
- **2026-10-07 · Lighthouse puts a script loaded just after `load` into the home page's LCP.** The load reveal makes the observed LCP late, so a 32 KB chunk imported on `requestIdleCallback` after `load` still finished before it and landed in the simulated critical chain (`network-dependency-tree-insight`): phone LCP went from 2.25 s to 2.50 s. Deferring it that way and dropping a parse-time `getContext("webgl2")` test both changed nothing. The zoom story now imports its code at the first scroll, swipe or key press, or when the section is two screens away (`ZoomStory.astro`). Check that chain before blaming bytes.
- **2026-10-07 · Pulling the page back with `scrollTo` during a touch fling makes it bounce.** The fling runs on the compositor, so each main-thread `scrollTo` fights it and recorded frames jump about 10 px back and forth for 0.3 s; the page's own `scrollY` log looks pinned. Setting `overflow: hidden` on `<html>` for that moment stops the fling (`zoom-story.js` `start()`).
- **2026-10-07 · Chrome does not retry a dynamic `import()` that failed.** After the zoom story's chunk answered 404 once, a second `import()` of it rejected at once without a request (the module map keeps the failure). `ZoomStory.astro` retries with the chunk's address taken from the error message plus a `?retry=` query; Safari's message names no address, so there the retry repeats the plain import.
- **2026-10-07 · A CDP `mouseWheel` with `deltaY: 100` scrolls 50 CSS px at `deviceScaleFactor: 2`.** The delta is in device pixels there, so wheel distances in check scripts halve on the 1440 x 900 at 2x runs; scale them by the device scale factor.
