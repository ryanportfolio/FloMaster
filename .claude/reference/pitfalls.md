# Pitfalls

> Accumulated project-specific gotchas. Dated entries, newest at the bottom. If this file exceeds ~200 lines, split by area (`pitfalls-<area>.md`) and update the CLAUDE.md index.

- **2026-10-05 · Git Bash turns a `/` page argument into a Windows path.** `node scripts/shoot.mjs /` navigated to `http://localhost:4321C:/Program Files/Git/`. Prefix page-path commands with `MSYS_NO_PATHCONV=1`.
- **2026-10-05 · Astro 7 runs one preview server at a time.** A second `astro preview` exits with "Another astro preview server is already running", and a kill queued in a Node `exit` handler never runs, so the first server lingered. Use `scripts/lib/preview.mjs` (reuses a running server, stops its own with a synchronous `taskkill`), or `npx astro preview stop`.
- **2026-10-05 · opentype.js 2.0 writes NaN into Cinzel's "M".** One horizontal segment has an undefined x, so `getPath().toPathData()` emits `LNaN`, and whole-string layout adds a ligature bug on top. `scripts/build-logo.mjs` lays out letter by letter and serializes path commands itself, carrying the previous point forward.
- **2026-10-05 · The check scripts only test the build on port 4321.** Every `scripts/check-*.mjs` calls `startPreview(4321)`, which reuses whatever preview answers there, so in a second worktree they silently test the main workspace's build. To check another build, serve its `dist/` on its own port with a plain static server (one existed for the repair-story bakeoff at `.tmp/arena/repair-story/serve.mjs`) and point a copy of the script at it. That server does not compress, so its page weights read about 100 KB higher than `astro preview`; compare raw HTML sizes instead.
- **2026-10-05 · `cmd //c mklink /J` fails from Git Bash.** MSYS rewrites `/J`, and mklink answers `Invalid switch`. Create a `node_modules` junction with Node instead: `fs.symlinkSync(target, path, "junction")`.
- **2026-10-05 · 2x full-page phone screenshots of long pages come back scrambled.** The home page at 375 px is about 14,000 CSS px tall, so a `deviceScaleFactor: 2` full-page capture is about 28,000 device px, past Chrome's 16,384 px capture limit; the image repeats the top of the page partway down. The page itself is fine. For review, capture long pages at device scale 1, or capture viewport-sized pieces.
- **2026-10-05 · Clicking a `tel:` link in automated Chrome blocks every later navigation in that page.** Chrome holds an "open this app?" prompt, so a following click or `goto` never commits (`waitForURL` timed out). Click `tel:` links last, or in their own page.
- **2026-10-05 · Speculation-rules prerenders never activate while Playwright is attached.** Chrome reports `PrerenderingDisabledByDevTools` for every attempt, with any context options. Scripts can only confirm an attempt starts (CDP `Preload` events); check activation by hand in plain Chrome (DevTools, Application, Speculative loads).
- **2026-10-05 · Chrome runs a cross-document view transition for the booking hand-off.** The `location.href = "/book/confirmed"` 500 ms after submit still counts as user-initiated (it runs inside the click's activation), contrary to the recon note that scripted navigations never transition. `/book/confirmed` arrives with the page transition; `scripts/check-transition.mjs` only requires it to finish cleanly.
- **2026-10-05 · `getComputedStyle(document.documentElement, "::view-transition-…(name)")` for a group that does not exist crashes the Chrome tab** ("Target crashed"). Only read view-transition pseudo-elements that the current pass creates (for example `fm-tide` only in the full pass).
- **2026-10-05 · A view-transition root picture keeps the page background behind named elements.** Giving the header its own group does not leave a see-through hole in the root picture: its slot shows the body background (paper white), so a header that moves during the transition uncovers a white strip. The site avoids it by keeping the header at the same place on every page: the prototype review bar rides inside the sticky header instead of scrolling away above it.
- **2026-10-05 · Never move a view transition's animation start times after it starts.** The band and the reveal run on the compositor, which keeps drawing frames while the main thread is stuck on a slow first frame; moving `startTime` forward afterwards drew the band backwards (gone for a frame, then back higher up). Presented frames only show this in a trace filmstrip, not in `requestAnimationFrame` timings. `scripts/check-transition.mjs` forces an 80 ms stall and checks the filmstrip.
- **2026-10-05 · Chrome does not scroll a focused element that is already partly in view**, even when its lower part sits under the phone bottom bar or its upper part under the sticky top area. With the taller prototype top area this made `check-keyboard` fail on the callback textareas and the home service cards; `TagSwitch.astro` scrolls such an element clear on `focusin`, only when the last input was a key press: scrolling on mouse focus made a click inside a focusable panel, a text field or the repair slider jump the page. `:focus-visible` cannot make that call, because Chrome sets it for clicked text fields, a mouse-focused range input and focus moved by script.
- **2026-10-05 · Subagents share one `mcp__playwright-iso__*` browser.** The MCP server belongs to the session, so parallel subagents from one session drive the same tab: one reviewer's navigation moved another reviewer's page mid-check. `--isolated` keeps the profile throwaway; it does not give each agent its own browser. Parallel browser work in subagents goes through `launchPlacedChrome()`, one Chrome per agent.
